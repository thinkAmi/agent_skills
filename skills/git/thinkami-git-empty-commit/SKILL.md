description: 空コミット(git commit --allow-empty)を適切なメッセージ付きで作成する。ユーザーが「空コミット」「empty commit」を作りたいとき、リポジトリやブランチの開始時点のコミットを作りたいときに使用する。
license: MIT

空コミットを作成します。以下の手順に従ってください。

1. 安全確認: `git diff --cached --quiet` を実行する。ステージ済みの変更が
   ある場合は**中断**してユーザーに知らせること。`--allow-empty` はステージ
   済み変更をそのままコミットしてしまい、空コミットにならないため。
   勝手にステージを解除したり、変更ごとコミットしたりしてはいけない。
2. git リポジトリでない場合は、先に `git init` の実行を提案する。
3. コミットメッセージを決める:
   - ユーザーがメッセージを指定した場合: そのメッセージを最優先で使う。
   - 指定がない場合: `chore: initial commit`(リポジトリ開始・ブランチ開始
     とも共通。履歴の先頭以外にこのメッセージがあれば、そこがブランチの
     開始点だと読み取れる)
4. `git commit --allow-empty -m "<メッセージ>"` を実行し、コミットハッシュと
   メッセージを報告する。
